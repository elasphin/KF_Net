## SmartPNT Dataset

This project uses the SmartPNT-MSF dataset.

Dataset source:
https://gitee.com/lv-jiarui/SmartPNT-MSF-Datasets

Related paper:
https://arxiv.org/abs/2507.19079

Download the dataset and place the required files in the following structure:

Dataset/
├── Data01_20230102_ISA-100C_Vehicle_Complex/
├── Data02_20220309_ISA-100C_Vehicle_Complex/
├── IMUErrorModel.txt
└── LEO_TLE/

The dataset files are not included in this repository.
